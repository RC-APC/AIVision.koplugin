# AIVision for KOReader

在 Kindle 上**长按选中一段文字 → 直接生成配图**，画面对比电子墨水屏优化，存本地随时翻看。

**Kindle 直连国内生图 API，不需要电脑、不需要中继、不需要翻墙。**

当前版本：**v2.2.0**（更新内容见 [CHANGELOG](CHANGELOG.md)）

---

## 特点

- **零中继**：Kindle 直接用 `ssl.https` 调用国内 API（智谱 / 豆包），电脑关机也能用
- **国内后端**：智谱 CogView、字节豆包 Seedream，服务器在国内，不受网络封锁影响
- **免费可用**：智谱 CogView 免费档为主力，豆包 Seedream 200 张免费额度作兜底
- **墨水屏优化**：自动追加「黑白水墨 / 高对比 / 无文字」风格后缀，e-ink 上看得清
- **记录画廊**：所有生成过的图存在本地，随时翻看，可一键清空历史记录
- **三个入口**：选区按钮、☰ 菜单、手势绑定，任选其一

## 安装

1. 下载本仓库的 `AIVision.koplugin` 整个目录
2. 通过 USB / 网络传输放到 Kindle 的 `koreader/plugins/` 下（若已有同名目录，直接覆盖）
3. 重启 KOReader


---

## 配置 API Key

插件需要至少一个后端的 API Key，在任一入口里配置：

> ☰ 菜单 →「AI 生图」→「设置智谱 Key」 /「设置豆包 Key」

或在手势设置里绑定对应动作。Key 保存在 `koreader/data/aivision/config.json`，**不会写入插件源码**。

### 推荐：智谱 CogView（免费）

1. 前往 [bigmodel.cn 开放平台](https://open.bigmodel.cn/) 注册
2. 在「API 密钥」中新建一个 Key
3. 填入本插件的「设置智谱 Key」

使用模型 `cogview-3-flash`，免费档。**默认带 AI 水印**；如需去水印，可在 bigmodel.cn 个人中心 → 安全管理签署免责声明后开启。

### 可选：豆包 Seedream（兜底，200 张免费）

1. 前往 [火山方舟](https://www.volcengine.com/product/ark) 注册
2. 开通图片生成，创建推理接入点，获取 API Key
3. 填入「设置豆包 Key」

作为智谱失败时的自动兜底后端。填了才启用。

## 使用

**方式一（推荐）：长按选段**  
在阅读界面长按选中文字 → 弹出的菜单里有多个按钮：

- **「AI 生图」**（原有）：直接为这段文字生成配图，存进画廊，不与高亮绑定。
- **「高亮并生图」**（新增）：先为这段**创建高亮**，再生成配图并把图**绑定到该高亮**。生成成功后提示「图片生成成功，点击高亮文本查看」——以后翻到这段、点一下高亮文字，菜单里就会出现「查看插图」。

> 若你只想随手生图、不打算绑到段落，**点「AI 生图」即可**，和以前一样。

等待约 10–30 秒 → 自动弹出成品图。

**绑定后怎么看插图**：点开**已生成插图的高亮文本** → 弹出的菜单里会出现 **「查看插图」**（已有高亮但还没插图时则显示「重绑插图」可重新生成）。插图保存在 KOReader 的高亮元数据里，**不改书籍正文**，关闭文档后随高亮一起保存。

**方式二：☰ 菜单**  
打开「AI 生图记录」查看历史生成记录，点任意一条即可查看大图。部分机型菜单内没有，可选用其他两种方式使用。

**方式三：手势**  
在 KOReader 手势设置中，把「AI 生图记录」绑定到你顺手的轻点/滑动位置。

> 生成过程中 Kindle 主线程会短暂等待（同步请求），属正常现象。

## 图片存放在哪 / 怎么删除

图片全部存放在 Kindle 本地：

```
koreader/data/aivision/
├── images/          ← 生成的图片（PNG）
├── config.json      ← 你的 API Key（已被 .gitignore 忽略）
└── queue.json       ← 生成记录列表
```

在 Kindle 上查看该目录：连接 USB 后位于 `mnt/us/koreader/data/aivision/`。

### 在插件内清空

进入「AI 生图记录」画廊，轻点顶部的 **「🗑 清空历史记录」**（与「设置 Key」同层级），会弹二次确认。

⚠️ **该操作只清空记录列表，不会删除图片文件。** 图片仍留在 `images/` 目录，需要你用 Kindle 文件管理器或 USB 手动删除。画廊底部会常驻显示图片目录路径，方便你直接定位。

> 记录超过 50 条时，最早的记录会从列表中自动移除（其图片文件同样保留，需手动清理）。

## 工作原理

```
长按选中文字
   ↓
拼接提示词 = 选中文字 + 墨水屏风格后缀
   ↓
POST https://open.bigmodel.cn/api/paas/v4/images/generations   （智谱 CogView）
   │ 失败则降级
   ↓
POST https://ark.cn-beijing.volces.com/api/v3/images/generations （豆包 Seedream）
   ↓
下载 data[1].url → 存为本地 PNG → 弹出看图
```

图片和记录都存在 Kindle 本地（`koreader/data/aivision/`），**不上传任何数据到第三方服务器**；唯一的外部请求是把你选中的那段文字发送给所选生图后端。

## 常见问题

**Q：长按选段没看到「AI 生图」？**  
先重启 KOReader。若仍无，检查 ☰ 菜单里是否存在「AI 生图」子菜单——有菜单说明插件已加载，只是选区按钮注入需要进入一次正文页面才会生效。

**Q：提示「还没配置 Key」？**  
去「AI 生图记录」里填写智谱或豆包 Key。

**Q：一直显示「生成中」或提示网络错误？**  
确认 Kindle 能正常访问公网（家宽 WiFi 或手机热点均可，国内站点畅通）。若之前生成的失败记录卡在「生成中」，重新生成即可。

**Q：图上有 AI 水印？**  
`cogview-3-flash` 免费档自带水印，去水印需在 bigmodel.cn 个人中心签署免责声明。
